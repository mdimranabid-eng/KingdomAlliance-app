Testing Setup

  • Create at least 2 test accounts (1 male/groom, 1 female/bride)
  • Test the full flow: Register → Onboarding → Pending → Approved → Match → Interest → Connect → Message
  • Use incognito/private browsing for clean session tests
  • Keep browser DevTools open to monitor network and console errors

Rate Limits

  • Interest sending: Max 5 per user per 24 hours (enforced server-side)
  • OTP verification: Attempt-limited, time-limited, hashed storage
  • Gallery photos: Max 3 gallery + 1 profile = 4 total
  • Photo file size: Max 10MB per image
  • Photo formats: JPEG, PNG, WEBP only
  • Password (registration): Min 8 chars, must include number + symbol
  • Password (reset): Min 6 characters
  • Bio length: Max 1200 characters
  • Session timeout: 15 min (user) / 10 min (admin)
  • Profile ID search: Min 6 characters
  • Account deletion: 7-day grace period
  • OTP resend: 120-second cooldown

Key Workflows to Test

  • Complete registration-to-connection flow end-to-end
  • Photo upload → moderation → approval/rejection cycle
  • Interest rate limit enforcement (send 5 in 24h)
  • Block/unblock user between two accounts
  • Account deletion and 7-day reactivation
  • Password reset flow with OTP
  • Multiple browser tabs state synchronization

Bug Reporting Format

  • Test Case #: Reference the number from this checklist
  • Steps to Reproduce: Exact steps taken
  • Expected: What should have happened
  • Actual: What actually happened
  • Severity: Critical / Major / Minor / Cosmetic
  • Screenshot: Attach if possible
  • Browser/Device: Include browser version and device type
